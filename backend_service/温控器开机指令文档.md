# 温控器开机指令文档

## 概述
本文档详细说明了温控器设备的开机指令格式、API接口调用方法以及MQTT协议配置。

## API接口

### 开机接口
- **接口路径**: `POST /api/thermostat/devices/{deviceId}/power-on`
- **请求方法**: POST
- **认证方式**: Bearer Token (JWT)
- **Content-Type**: application/json

### 请求参数

#### 路径参数
- `deviceId` (string, 必需): 温控器设备ID

#### 请求体参数 (可选)
```json
{
  "target_temp": 22,     // 目标温度 (°C)
  "fan_speed": 1,        // 风速等级 (0-3)
  "ac_mode": "cool"      // 空调模式: "cool", "heat", "auto", "fan", "dry"
}
```

### 响应格式
```json
{
  "success": true,
  "message": "温控器开机成功",
  "data": {
    "deviceId": "b3af27a4-9cfa-4a47-a359-f0870cb70b99",
    "command": {
      "body": {
        "setOn": 1,
        "id": [1]
      },
      "func": "write",
      "uuid": "869861065084704",
      "pType": "params"
    }
  }
}
```

## MQTT控制指令

### 指令格式
```json
{
  "body": {
    "setOn": 1,
    "id": [1]
  },
  "func": "write",
  "uuid": "869861065084704",
  "pType": "params"
}
```

### 字段说明
- `body.setOn`: 开关机状态 (1=开机, 0=关机)
- `body.id`: 内机编号数组，默认为 [1]
- `func`: 功能类型，固定为 "write"
- `uuid`: 设备IMEI号 (温控器厂商要求使用IMEI而非设备ID)
- `pType`: 参数类型，固定为 "params"

### MQTT主题
- **控制主题**: 根据设备的 `manufacturer_code` 和 `subscription_type` 动态构建
- **响应主题**: 设备会在相应的响应主题发布状态更新

### MQTT配置
- **QoS**: 1 (至少一次传递)
- **Retain**: false
- **超时时间**: 30秒
- **协议类型**: JSON

## 使用示例

### cURL调用示例
```bash
curl -X POST "http://localhost:3003/api/thermostat/devices/b3af27a4-9cfa-4a47-a359-f0870cb70b99/power-on" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -d '{
    "target_temp": 22,
    "fan_speed": 1,
    "ac_mode": "cool"
  }'
```

### JavaScript调用示例
```javascript
const response = await fetch('/api/thermostat/devices/b3af27a4-9cfa-4a47-a359-f0870cb70b99/power-on', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({
    target_temp: 22,
    fan_speed: 1,
    ac_mode: 'cool'
  })
});

const result = await response.json();
console.log(result);
```

## 协议配置

### 设备协议模板
```json
{
  "commands": {
    "power_on": {
      "template": {
        "body": {
          "setOn": 1
        },
        "func": "write",
        "uuid": "{device_id}",
        "pType": "params"
      }
    }
  }
}
```

## 重要说明

1. **设备标识**: 温控器厂商要求在MQTT指令中使用设备的IMEI号作为uuid，而非系统内部的device_id

2. **内机编号**: 所有控制指令必须包含 `id` 字段，用于指定内机编号，默认为 [1]

3. **租户权限**: 调用API时必须使用正确租户的认证token，确保设备所属租户与token中的租户ID匹配

4. **异步响应**: MQTT指令发送后，设备状态更新是异步的，可通过WebSocket或轮询API获取最新状态

5. **错误处理**: 如果设备离线或协议配置错误，API会返回相应的错误信息

## 相关接口

- **关机接口**: `POST /api/thermostat/devices/{deviceId}/power-off`
- **设置温度**: `POST /api/thermostat/devices/{deviceId}/temperature`
- **设置模式**: `POST /api/thermostat/devices/{deviceId}/mode`
- **设置风速**: `POST /api/thermostat/devices/{deviceId}/fan-speed`
- **获取状态**: `GET /api/thermostat/devices/{deviceId}/status`
